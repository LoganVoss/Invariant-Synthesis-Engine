# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities in a public issue. Contact the repository
owner privately with a minimal reproduction, affected version, expected impact, and any
suggested mitigation. Acknowledgement and disclosure timing will be coordinated with the
reporter.

## Safety boundary

Invariant Synthesis Engine is research software and a read-only decision-support layer. It
has not been certified for autonomous control of critical infrastructure, industrial
equipment, vehicles, medical systems, or financial execution. Integrators are responsible
for authentication, authorization, data governance, deployment isolation, independent
validation, and fail-safe design.
